## How to test

1. Run the updated source build and open **Setup agent** in the header, or **Plan with the setup agent** on Projects. Choose GPT or Claude with an existing stored key.
2. Describe the detector and desired model. Review/edit the proposed name, classes and starter, choose a new project folder, and select **Create project**. Home opens while setup remains available.
3. Choose an image folder and **Import images**. Starter acquisition/import run with progress. Close/reopen the drawer; the created project and current step remain.
4. Select a small representative image batch, edit labeling instructions, then **Estimate first labeling**. Review the approximate charge and **Start first labeling**. Changing inputs requires a fresh estimate.
5. Select **Review suggestions** after completion; accept/edit/reject before building a training dataset. Labels are never automatically accepted.
6. In **Models**, choose a different family, then its size and **Download and add**. Only the selected model downloads; it becomes available as a training base.
