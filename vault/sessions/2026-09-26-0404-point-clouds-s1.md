4. **Measure** → Vertical check → base then top of the stack → offset, lean, azimuth, mm/m and ± u → Save; **Copy all as CSV**.
5. Link the ortho on **Details**; on the map right-click → **Open this spot in 3D** → the view arrives on the surface with a pin; pick → **Show on map** → marker.
6. **Export LAZ** → toast → **Show folder**; open the LAZ in QGIS: it sits on the stack in EPSG:32639.
7. Start the 3×3 import and cancel it from Jobs: no PotreeConverter process remains; the cloud says "import cancelled".
