## Why

- The operator hit "Option 'tsBuildInfoFile' cannot be specified without specifying option
  'incremental' or option 'composite'" and asked for a clean-codebase pass. `pnpm build` runs
  `tsc -b`, which implies incremental, so the gate never showed the error. It reproduces only on
  TypeScript < 5.6 (checked with 5.5; 5.9 no longer runs that check), i.e. an editor or tool
  loading an older TypeScript. TS 6.0.3 flags `baseUrl` as deprecated (error TS5101), and TS 7.0.2
  rejects it outright, so that went too.
