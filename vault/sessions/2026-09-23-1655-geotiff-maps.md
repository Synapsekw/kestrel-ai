## Why

The operator asked for a way to judge models on the artefact customers actually deliver — an
orthomosaic — rather than on drone frames: counts per class over a whole site, the boxes visible on
the imagery, and coordinates that leave the app for GIS. Frame metrics do not answer "how many
excavators are on this site", and nothing in the app could open a multi-GB GeoTIFF at all.

## How to test

1. Install the build: run
   `frontend\src-tauri\target\release\bundle\inno\Kestrel AI_0.1.0_x64-setup.exe /VERYSILENT`, then
   open Kestrel AI. Restart any backend started before the merge — it keeps serving the old routes.
2. **Maps** in the left rail → **Import map** → a real orthomosaic `.tif`. It appears in the list
   with a progress bar and becomes clickable when the import finishes (about 1–3 min per GB); the
   source file's size and modified time must be unchanged.
3. Click the map: it fills the work area. Scroll-zoom from the whole site to a single machine —
   tiles arrive in about a second per view with no seams, and the bottom bar shows pixel, EPSG and
   lat/lon under the cursor with a scale bar.
4. **New run** → pick a model, check "Model trained at (cm / px)" against the map's own resolution
   → **Start detection**. Progress reads "window n / N · k detections"; cancel, then **Resume**
   continues rather than restarting.
5. Tick the finished run: boxes land on machines, the Results table shows counts per class, the
   confidence slider moves boxes and counts together, and zooming far out turns boxes into density
   dots. Tick a second run for solid/dashed outlines and side-by-side counts.
6. **Labels** tab: draw a zone, **Copy detections into labels**, then correct them (`1`–`9` class,
   `B` box, drag to move/resize, `Del`, `Ctrl+Z`/`Ctrl+Y`). With a box selected, picking a class
   reclasses it; with nothing selected it sets the next box's class.
7. **Score** tab: precision, recall, F1 and count error per run; "Colour boxes by result" turns
   boxes green/red/amber-dashed; **Next mistake** flies to each error.
8. **Export** → "Run scored against labels" → all three formats → the Export screen's **Past
   exports** → reveal. **Open the `.gpkg` in QGIS** — this is the one check nothing has ever run.
   Open the `.csv` in Excel: four corners per box in both the map's CRS and lat/lon.
9. Import a TIFF with no georeferencing: view/detect/label/score still work, and Export offers only
   CSV with the reason stated.
