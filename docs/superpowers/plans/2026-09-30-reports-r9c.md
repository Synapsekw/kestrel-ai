# Reports R9-C: 3D views in finding pages and cloud measurements — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** print C's stored 3D report view for every cloud finding and cloud measurement (passed through, re-encoded once as JPEG q88 into the snapshot cache), warn when a view is out of date, and fall back to a hillshade plan of a cloud-derived elevation item or to a placeholder with a capture deep link when no view exists. This unit replaces R3's stub `snapshots/view3d.py` and R2's stub `figures/cloud.py`.

**Architecture:** `snapshots/view3d.py` is the renderer pair for R0's `view3d` SnapshotSpec kind: `source_version` is the stored view's sha256 (so a re-capture changes the key), and `render` reads the one stored PNG/JPEG through `app.pointclouds.views.stored_view` and returns an RGB image; R3's `render_to_cache` does the caching and the encode. `figures/cloud.py` holds two compose hooks (`finding_figures` for R2's `finding_pages`, `measurement_figure` for R9-M's `measurements` section). Each does a few primary-key reads, decides view / hillshade fallback / placeholder, adds aggregated builder warnings to `ctx.warnings`, and returns figures that only *reference* snapshots (spec §8.2 step 4). R never reads `cloud_view` directly; everything goes through C's `views.py`.

**Tech Stack:** Python 3.11, SQLAlchemy 2 (project DB, SQLite `json_extract`), Pillow 12.3.0, pydantic v2 (R0's schemas), pytest.

**Spec:** `docs/superpowers/specs/2026-09-26-reports-design.md` (§3 row C, §9.1 `view3d`, §9.4 in full, §9.5, §15, §16, §21 risk 2). Binding, in order: `docs/superpowers/plans/2026-09-30-reports-index.md` ("Interface decisions", "Coordinator rulings"), `.superpowers/sdd/imc-common/programme-rulings.md`, then the spec. ## Review Focus

1. **A finding whose view file was deleted from disk (row still present)**: `stored_view` returns None, so compose takes the fallback path and never a broken figure. Pinned in Task 3 (`test_a_row_without_its_file_is_treated_as_missing`).
2. **A view re-captured after a report was composed (new sha256)**: the key changes, so the preview and the next render never serve the old cached image (spec §9.1 "a stale snapshot impossible"). Pinned in Task 1 (`test_the_key_changes_when_the_view_is_recaptured`).
3. **A view deleted between compose and render** (finding deleted, or C's measurement delete removed it): `render` raises `LookupError` and R3 prints a placeholder; the job does not fail. Pinned in Task 1 (`test_a_vanished_view_raises_lookup_error`) and Task 5 (`test_a_vanished_view_renders_a_placeholder`).
4. **A cloud-derived surface from a different cloud, or one still building or failed, that happens to cover the XY**: never chosen. Only a `ready` `cloud_dsm` of the **same** cloud (same CRS by construction) is used. Pinned in Task 2 (`test_only_a_ready_dsm_of_the_same_cloud_covers`).
5. **A report with 300 cloud findings and no views**: the builder shows one "300 3D views are missing" warning, not 300 warnings. Pinned in Task 3 (`test_warnings_aggregate_to_one_entry_per_code`).

## Rulings (spec ambiguities decided here)

1. **Figure sizes.** A stored view is 1600×1000 (1.6:1), so the main view3d figure prints **170×106 mm** (§7.3's 170×105 mm rounded to the view's aspect, ≈ 239 dpi) with `width_px=1600, height_px=1000`. The hillshade fallback is R3's 4:3 elevation render, `out [1200, 900]`, printed **140×105 mm** (the same rule as R9-I Ruling 1).
2. **One figure per cloud finding.** A finding has one anchor (F's model), so a cloud finding page gets exactly one main figure. No secondary locator in v1: it would double the snapshot work per cloud finding for little gain.
3. **Which surfaces count as "a cloud-derived elevation item covering the anchor".** `Surface.kind == "cloud_dsm"`, `status == "ready"`, `point_cloud_id ==` the anchor's cloud, and `bounds_native` (`[minx, miny, maxx, maxy]`) containing the anchor XY. Such a surface is built from that cloud, so its CRS is the cloud's and no transform is needed. The newest wins (`created_at desc, id desc`). Surfaces of other clouds are ignored, even overlapping ones: their CRS may differ, and "covers" would need a reprojection R does not own.
4. **Fallback geometry.** A finding: `{"type": "Point", "coordinates": [x, y]}`. A measurement: the coverage test uses the centroid of its points' XY (§9.4). The drawn geometry is a closed Polygon of `area_vertices(points)` for an `area` measurement with ≥ 3 vertices, and otherwise a Point at the centroid. R3's elevation renderer draws Points and Polygons only (§9.3 step 5).
5. **Warnings.** A missing view warns in **both** fallbacks (§8.2 step 5 "n findings have no 3D view"; capture repairs it), code `view3d_missing`. A stale view prints and warns `view3d_stale`. Each code is **one** aggregated `ReportWarning` per compose. Its message starts with the count, and its `link` is the first subject's deep link (bounded, and one click lands where "Capture missing views" repairs all of them). The count is kept on the warning itself: the helper re-parses the leading integer of its own message. That is deterministic because only this module writes these codes.
6. **The placeholder is a `view3d` ref with `missing_reason`**, not a separate spec kind. Its key uses `source_version == "no_view"`, so once a view is captured the key changes and the real view prints. Rendering it makes `render` raise `LookupError(reason)`, which R3's `render_to_cache` turns into its grey placeholder with that reason (the same path as a view vanished at render time).
7. **Captions.** A view: `"3D view, captured 24 Sep 2026"`; a stale view adds `" (out of date: the anchor moved after capture)"`. A hillshade: `"Plan view of <surface name>: no 3D view saved"`. A placeholder: `"No 3D view"`. For a measurement, `"<measurement name>: "` is prefixed to each.
8. **JPEG q88.** `view3d.JPEG_QUALITY = 88` is declared on the renderer module. If R3's merged `render_to_cache` reads a per-kind quality (a module attribute, a `QUALITY` map or a renderer return value), wire q88 through it (Task 1 Step 1 records how). If it does not, the cache stays at R3's q85: record it as a hand-off to R3 in the task report, mark `test_the_cache_holds_a_q88_passthrough` `xfail(strict=True, reason="R3 hand-off: per-kind JPEG quality")`, and do not edit R3's files.
9. **Alpha.** A PNG view with an alpha channel is flattened on white (paper), never on black.
10. **`measurement_figure` on a deleted measurement** (a race between R9-M's page read and this call) returns a placeholder figure with reason "The measurement no longer exists" and no warning.

```python
def cloud_finding(handle, type_id: str, cloud_id: str, *, x=X, y=Y, z=Z) -> Finding:
    anchor = AnchorIn(kind="cloud", cloud_id=cloud_id, x=x, y=y, z=z)
    return service.create_finding(handle, type_id=type_id, anchor=anchor)


def cloud_measurement(handle, cloud_id: str, *, kind: str = "distance", points=None, name="M1") -> str:
    """A cloud_measurement row inserted directly (results are not what R9-C reads)."""
    points = points or [
        {"x": X - 5.0, "y": Y, "z": Z, "uncertainty_m": 0.01},
        {"x": X + 5.0, "y": Y, "z": Z, "uncertainty_m": 0.01},
    ]
    with handle.session() as s:
        m = CloudMeasurement(point_cloud_id=cloud_id, kind=kind, name=name, points=points, results={})
        s.add(m)
        s.flush()
        return m.id


def store_finding_view(handle, finding_id: str, data: bytes | None = None):
    meta = views.parse_meta(meta_json(), "finding")
    return views.store(handle, views.finding_subject(handle, finding_id), data or png(), meta)

    meta = views.parse_meta(meta_json(), "cloud_measurement")
    subject = views.measurement_subject(handle, cloud_id, measurement_id)
    return views.store(handle, subject, data or png(), meta)


def make_stale(handle, *, finding_id: str | None = None, measurement_id: str | None = None) -> None:
    """The anchor 'moved since capture': C computes stale = anchor_hash != hash(current geometry)."""
    col = CloudView.finding_id if finding_id else CloudView.cloud_measurement_id

        s.execute(update(CloudView).where(col == (finding_id or measurement_id)).values(anchor_hash="moved"))
```

```python
"""view3d: C's stored report view passed through (reports spec §9.1, §9.4; unit R9-C).

R does not render point clouds. The one stored PNG/JPEG (at most 6 MiB, 1600 x 1000, checked by C
at upload) is read through `app.pointclouds.views.stored_view`, never the `cloud_view` table, and
returned as RGB; R3's `render_to_cache` re-encodes it once as JPEG (q88, `JPEG_QUALITY`) into the
cache, and turns a `LookupError` into its placeholder with the reason."""

from __future__ import annotations

from PIL import Image as PILImage

from app.pointclouds import views

OUT = (views.WIDTH, views.HEIGHT)
JPEG_QUALITY = 88
NO_VIEW = "no_view"
MISSING = {
    "finding": "No 3D view saved. Open this finding in Point clouds to capture one",
    "cloud_measurement": "No 3D view saved. Open this measurement in Point clouds to capture one",
}


def source_version(handle, spec) -> str:
    """The stored view's sha256 (the ETag of C's GET …/view3d), or "no_view": a re-capture changes
    the snapshot key, so a cached old view is never served (spec §9.1)."""
    view = views.stored_view(handle, spec.subject_kind, spec.subject_id)
    return view.meta.sha256 if view is not None else NO_VIEW


def render(handle, spec) -> PILImage.Image:
    """The stored view as RGB, exactly OUT: alpha flattened on white; another size fitted inside,
    never enlarged, centred on white. LookupError(reason) when the view or its file is gone."""
    view = views.stored_view(handle, spec.subject_kind, spec.subject_id)
    if view is None:
        raise LookupError(MISSING[spec.subject_kind])
    try:
        with PILImage.open(view.path) as im:
            if im.format == "JPEG":
                im.draft("RGB", OUT)
            im.load()
            picture = _flatten(im)
    except FileNotFoundError as e:
        raise LookupError(MISSING[spec.subject_kind]) from e
    if picture.size == OUT:
        return picture
    picture.thumbnail(OUT, PILImage.Resampling.LANCZOS)
    page = PILImage.new("RGB", OUT, (255, 255, 255))
    page.paste(picture, ((OUT[0] - picture.width) // 2, (OUT[1] - picture.height) // 2))
    return page


def _flatten(im: PILImage.Image) -> PILImage.Image:
    if im.mode in ("RGBA", "LA") or (im.mode == "P" and "transparency" in im.info):
        rgba = im.convert("RGBA")
        page = PILImage.new("RGB", rgba.size, (255, 255, 255))
        page.paste(rgba, mask=rgba.getchannel("A"))
        return page
    return im.convert("RGB")
```

```python
"""3D views for cloud findings and cloud measurements (reports spec §9.4; unit R9-C).

Compose hooks only: per subject a few primary-key reads through C's `views.stored_view` (never the
`cloud_view` table), at most one LIMIT-1 surface query, and figures that only reference their
snapshot (spec + key); R3's cache renders them later. Fallbacks when no view is saved: a hillshade
plan of a ready cloud DSM of the same cloud covering the anchor, else a placeholder."""

from __future__ import annotations

import re

from sqlalchemy import func, select

from app.db.models import Surface
from app.reports.schemas import ReportWarning

STALE = "view3d_stale"
MISSING_CODE = "view3d_missing"
_WORDING = {
    STALE: ("1 3D view is out of date", "{n} 3D views are out of date"),
    MISSING_CODE: ("1 3D view is missing", "{n} 3D views are missing"),
}
_COUNT = re.compile(r"^(\d+) ")


def deep_link(project_id: str, cloud_id: str, finding_id: str | None = None) -> str:
    """Where "Capture missing views" / Refresh view repairs it (spec §9.4, F §8.7)."""
    base = f"/p/{project_id}/clouds/{cloud_id}"
    return f"{base}?finding={finding_id}" if finding_id else base


def covering_surface(handle, cloud_id: str, x: float, y: float) -> tuple[str, str] | None:
    """(id, name) of the newest ready cloud DSM built from `cloud_id` whose bounds hold (x, y).
    Same cloud, so same CRS; one LIMIT-1 query (Ruling 3)."""
    b = Surface.bounds_native
    q = (
        select(Surface.id, Surface.name)
        .where(
            Surface.kind == "cloud_dsm",
            Surface.status == "ready",
            Surface.point_cloud_id == cloud_id,
            b.is_not(None),
            func.json_extract(b, "$[0]") <= x,
            func.json_extract(b, "$[1]") <= y,
            func.json_extract(b, "$[2]") >= x,
            func.json_extract(b, "$[3]") >= y,
        )
        .order_by(Surface.created_at.desc(), Surface.id.desc())
        .limit(1)
    )
    with handle.session() as s:
        row = s.execute(q).first()
    return (row[0], row[1]) if row else None


def warn(ctx, code: str, link: str) -> None:
    """One aggregated warning per code; the count is the leading integer of this module's own
    message (Ruling 5); the link stays the first subject's."""
    one, many = _WORDING[code]
    for i, w in enumerate(ctx.warnings):
        if w.code == code:
            n = int(_COUNT.match(w.message).group(1)) + 1
            ctx.warnings[i] = w.model_copy(update={"message": many.format(n=n)})
            return
    ctx.warnings.append(ReportWarning(code=code, message=one, link=link))
```

```python
def finding_figures(ctx, finding) -> list[Figure]:
    """[] unless a cloud finding; else its one main figure: the stored view, the hillshade plan of a
    covering cloud DSM, or a placeholder with the capture reason (spec §9.4)."""
    if finding.anchor_kind != "cloud":
        return []
    with ctx.handle.session() as s:
        row = s.get(Finding, finding.id)
        if row is None or row.cloud_id is None:
            return []
        cloud_id, x, y = row.cloud_id, row.x, row.y
    link = deep_link(ctx.handle.id, cloud_id, finding.id)
    spec = View3dSpec(kind="view3d", subject_kind="finding", subject_id=finding.id, cloud_id=cloud_id)
    view = views.stored_view(ctx.handle, "finding", finding.id)
```

```python
GONE = "The measurement no longer exists"


def measurement_figure(ctx, row) -> Figure:
    """The cloud measurement's stored view, or the hillshade plan of a cloud DSM covering its
    centroid, or a placeholder (spec §9.4). `row` is a MeasurementItem with kind "cloud"."""
    if row.kind != "cloud":
        raise ValueError(f"measurement_figure is for cloud measurements, not {row.kind!r}")
    prefix = f"{row.name}: "
    cloud_id = row.data_id
    spec = View3dSpec(kind="view3d", subject_kind="cloud_measurement", subject_id=row.id, cloud_id=cloud_id)
    with ctx.handle.session() as s:
        m = s.get(CloudMeasurement, row.id)
        found = None if m is None else (m.point_cloud_id, m.kind, list(m.points or []))
    if found is None:
        return _placeholder_figure(ctx, spec, GONE, prefix=prefix)
    cloud_id, kind, points = found
    link = deep_link(ctx.handle.id, cloud_id)
    view = views.stored_view(ctx.handle, "cloud_measurement", row.id)
    if view is not None:
        if view.meta.stale:
            warn(ctx, STALE, link)
        return _view_figure(ctx, spec, view, prefix=prefix)
    warn(ctx, MISSING_CODE, link)
    if points:
        (cx, cy), geometry = fallback_geometry(kind, points)
        surface = covering_surface(ctx.handle, cloud_id, cx, cy)
        if surface is not None:
            return _plan_figure(ctx, surface, geometry, prefix=prefix)
    return _placeholder_figure(ctx, spec, view3d.MISSING["cloud_measurement"], prefix=prefix)


def fallback_geometry(kind: str, points: list[dict]) -> tuple[tuple[float, float], dict]:
    """(centroid XY, drawn geometry): an area's closed outline, else a pin at the centroid (Ruling 4)."""
    cx = sum(float(p["x"]) for p in points) / len(points)
    cy = sum(float(p["y"]) for p in points) / len(points)
    if kind == "area":
        ring = [[float(p["x"]), float(p["y"])] for p in area_vertices(points)]
        if len(ring) >= 3:
            return (cx, cy), {"type": "Polygon", "coordinates": [[*ring, ring[0]]]}
    return (cx, cy), {"type": "Point", "coordinates": [cx, cy]}
```

The spec is built with `row.data_id` before the read, so a deleted measurement still gets a well-formed placeholder ref.
