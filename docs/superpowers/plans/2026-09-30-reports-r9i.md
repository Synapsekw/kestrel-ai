# Reports R9-I: image anchors in finding pages, photos, comments — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** fill the per-finding page (spec §7.3) with the image-anchor figure (a crop of the annotation with the optional locator inset), the finding's photos (up to `photos_max`, 40×30 mm, print-size JPEGs through the snapshot cache) and its comment thread (`none | last | all`), by replacing R2's stub `figures/image.py` and R3's stub `snapshots/attachment.py`.

**Architecture:** `figures/image.py` holds three pure compose hooks that R2's `finding_pages` composer calls once per finding; each does bounded primary-key / `LIMIT n` reads in its own short session and returns blocks that only *reference* snapshots (`SnapshotRef` = spec + key), never render them (spec §8.2 step 4). `snapshots/attachment.py` is the renderer for R0's `attachment` SnapshotSpec kind: it decodes one attachment JPEG-draft-reduced, EXIF-transposes, and pads it to `out` on white; R3's `render_to_cache` does the caching, the JPEG q85 encode, the `Semaphore(2)` and the placeholder on failure.

**Tech Stack:** Python 3.11, SQLAlchemy 2 (project DB), Pillow 12.3.0, pydantic v2 (R0's schemas), pytest.

**Spec:** `docs/superpowers/specs/2026-09-26-reports-design.md` (§3 rows I annotations, F attachments/comments; §7.2 `finding_pages`; §7.3; §9.1; §9.2 step 5; §9.5; §15; §16; §17). ## Rulings (spec ambiguities decided here)

1. **Main figure size.** §7.3 draws the main snapshot 170×105 mm but §9.2 keeps a 4:3 crop. The crop stays 4:3: `out [1200, 900]`, printed **140×105 mm** (≈ 218 dpi), centred by R4/R6. No stretching, no letterbox.
2. **Locator inset** (`context_inset`, §7.2/§9.2 step 5) is the `inset` flag on the main `image_crop` spec; R3's `image_crop` renderer draws it from `datasets.images.thumbnail` (R3 owns §9.2 and the renderer; index ruling 4). R9-I sets the flag and pins it end to end in Task 5 (`test_the_inset_changes_the_crop_and_reads_the_thumbnail`). If R3's merged renderer ignores `inset`, that test fails: report it as a hand-off to R3 (do not edit `image_crop.py`), mark the test `xfail(strict=True, reason="R3 hand-off: inset")`, and continue.
3. **Which option decides the image figure.** R2's `finding_pages` decides whether to call `finding_figures` from `options.snapshots` (it contains `"image"`). `finding_figures` still reads `context_inset` itself from `ctx.config` (the `finding_pages` section's options; default `true` when absent).
4. **Ring by shape** (§3 row I): `box` → its 4 corners, `rbox` → `corners_of`, `polygon` → `points`, all via `app.imagery.shapes.outline`; `point` (`outline` is `None`) → `[[x, y]]`, drawn by R3 as a pin. A polygon with no stored `points` falls back to its envelope's corners.
5. **Label and colour** (§9.2 step 4): `"F-0042 · <type name>"` and the project type's `colour` from `ProjectType` (the project's snapshot of the catalogue type); an unknown type prints `"Unknown type"` in `#8F7BFF` (the print violet, §10.1).
6. **Caption of the main figure:** the image file's name (`Path(image.path).name`). The observed date, coordinates and provenance are R2's `kv` rows, not the caption.
7. **Photos** are the finding's attachments oldest first (`created_at, id`), the first `max_n`. `max_n` is clamped to 0–6. Each prints through the cache at `out [480, 360]` (40×30 mm ≈ 305 dpi), the photo fitted inside and padded **white** (paper), so every photo cell has the same size. Caption: the original file name, cut to 32 characters with "…".
8. **Photos for every anchor kind.** Attachments belong to the finding, not to the image anchor, so `photos` and `comments` work for map and cloud findings too.
9. **Comments.** `last` = the newest by `(created_at, id)`. `all` = oldest first, at most 100; when more exist, one trailing entry `{author: "Kestrel AI", text: "<n> more comments are not printed; see the finding in the app.", created_at: ctx.generated_at}` (deterministic). An edited comment prints its text as it is now; `edited_at` is not printed. Text is passed raw; escaping is the renderer's job (§8.1).
10. **Attachment spec guard.** The renderer loads the row by `attachment_id`, requires `row.finding_id == spec.finding_id`, and requires the resolved path to lie inside `<project>/findings/`; otherwise it raises `LookupError`, which R3's `render_to_cache` turns into a placeholder (and its endpoint's usual answer).
11. **`source_version` for `attachment`** = `f"{size}:{mtime_ns}"` of the file, or `"missing"` when the row or file is gone, so compose never raises and a replaced file changes the key (§9.1 "a stale snapshot impossible").

"""Rows for the R9-I tests (reports image figures, photos, comments): an image finding over a real
JPEG, its photos through F's own `attachments.add`, and a comment thread with fixed times."""

from __future__ import annotations

from datetime import UTC, datetime, timedelta
from pathlib import Path

from sqlalchemy import update

from app.db.models import Box, Finding, FindingAttachment, FindingComment, Image, Source
from app.findings import attachments, service
from app.findings.anchors import AnchorIn

T0 = datetime(2026, 9, 1, 8, 0, tzinfo=UTC)
GENERATED_AT = datetime(2026, 9, 30, 12, 0, tzinfo=UTC)


def image_finding(
    handle,
    type_id: str,
    make_jpeg,
    *,
    name: str = "a.jpg",
    size: tuple[int, int] = (1600, 1200),
    shape: str = "box",
    xywh: tuple[float, float, float, float] = (700.0, 500.0, 200.0, 150.0),
    angle: float = 0.0,
    points: list[list[float]] | None = None,
) -> tuple[Finding, str, str]:
    """A ground-truth box of `shape` on a real `size` JPEG, adopted as a finding; returns
    (finding, image_id, box_id). A polygon's `xywh` is its envelope; a point has w = h = 0."""
    make_jpeg(handle.folder / "images" / name, *size)
    with handle.session() as s:
        src = Source(folder="C:/flights/a", site="A")
        s.add(src)
        s.flush()
        image = Image(path=f"images/{name}", width=size[0], height=size[1], source_id=src.id)
        s.add(image)
        s.flush()
        x, y, w, h = xywh
        box = Box(
            image_id=image.id,
            class_id=type_id,
            x=x,
            y=y,
            w=w,
            h=h,
            angle=angle,
            shape=shape,
            points=points,
            provenance_kind="person",
            review_state="accepted",
        )
        s.add(box)
        s.flush()
        image_id, box_id = image.id, box.id
    f = service.create_finding(
        handle, type_id=type_id, anchor=AnchorIn(kind="image", image_id=image_id, annotation_id=box_id)
    )
    return f, image_id, box_id


def add_photos(handle, finding_id: str, folder: Path, make_jpeg, n: int, *, size=(640, 480)) -> list[str]:
    """`n` photos through F's own copy path, with created_at T0 + i s so their order is fixed."""
    ids = []
    for i in range(n):
        src = make_jpeg(folder / f"photo{i}.jpg", *size, seed=i)
        ids.append(attachments.add(handle, finding_id, str(src)).id)
    with handle.session() as s:
        for i, aid in enumerate(ids):
            s.execute(
                update(FindingAttachment)
                .where(FindingAttachment.id == aid)
                .values(created_at=T0 + timedelta(seconds=i))
            )
    return ids


def add_comments(handle, finding_id: str, n: int, *, author: str = "Dana") -> None:
    """`n` comments "c0".."c<n-1>", created T0 + i minutes."""
    with handle.session() as s:
        for i in range(n):
            s.add(
                FindingComment(
                    finding_id=finding_id, author=author, text=f"c{i}", created_at=T0 + timedelta(minutes=i)
                )
            )


def make_ctx(handle, **finding_pages_options):
    """A ComposeContext over the built-in full report, with `finding_pages` options overridden."""
    from app.reports.compose import ComposeContext
    from app.reports.schemas import ReportConfig
    from app.reports.templates.builtins import BUILTIN_TEMPLATES

    full = next(t for t in BUILTIN_TEMPLATES if t.id == "builtin-full")
    raw = full.config.model_dump(mode="json", by_alias=True)
    for section in raw["sections"]:
        if section["key"] == "finding_pages":
            section["options"] = {**(section.get("options") or {}), **finding_pages_options}
    config = ReportConfig.model_validate(raw)
    return ComposeContext(
        handle=handle, config=config, report_id="r-test", baseline=None, generated_at=GENERATED_AT
    )


def row_of(handle, finding_id: str):
    """The FindingRow R2's iterator yields for `finding_id` (the hooks' `finding` argument)."""
    from app.reports.compose import FindingRow

    with handle.session() as s:
        f = s.get(Finding, finding_id)
        return FindingRow.from_finding(f)

"""Image-anchor figures, photos and comments for the per-finding page (reports spec §7.2, §7.3,
§9.2; unit R9-I). Compose hooks only: every read is a primary-key get or a LIMIT query in its own
short session, and a figure only references its snapshot (spec + key); R3 renders it later."""

from __future__ import annotations

from sqlalchemy import func, select

from app.db.models import FindingComment
from app.reports.compose import ComposeContext, FindingRow
from app.reports.schemas import Comment

COMMENTS_ALL_MAX = 100
MORE_AUTHOR = "Kestrel AI"


def comments(ctx: ComposeContext, finding: FindingRow, mode: str) -> list[Comment]:
    """`none` -> []; `last` -> the newest; `all` -> oldest first, at most 100 plus a "more" line."""
    if mode not in ("last", "all"):
        return []
    q = select(FindingComment).where(FindingComment.finding_id == finding.id)
    with ctx.handle.session() as s:
        if mode == "last":
            rows = s.execute(
                q.order_by(FindingComment.created_at.desc(), FindingComment.id.desc()).limit(1)
            ).scalars()
            return [_comment(r) for r in rows]
        rows = list(
            s.execute(
                q.order_by(FindingComment.created_at, FindingComment.id).limit(COMMENTS_ALL_MAX + 1)
            ).scalars()
        )
        out = [_comment(r) for r in rows[:COMMENTS_ALL_MAX]]
        if len(rows) > COMMENTS_ALL_MAX:
            total = s.execute(
                select(func.count()).select_from(FindingComment).where(FindingComment.finding_id == finding.id)
            ).scalar_one()
            more = total - COMMENTS_ALL_MAX
            out.append(
                Comment(
                    author=MORE_AUTHOR,
                    text=f"{more} more comments are not printed; see the finding in the app.",
                    created_at=ctx.generated_at,
                )
            )
    return out


def _comment(row: FindingComment) -> Comment:
    return Comment(author=row.author, text=row.text, created_at=row.created_at)
```

from pathlib import PurePosixPath

from app.db.models import Box, Image, ProjectType
from app.findings.numbers import format_number
from app.geometry import corners_of
from app.imagery.shapes import outline
from app.reports.schemas import ImageCropSpec

MAIN_OUT = (1200, 900)  # 4:3, spec §9.2
MAIN_MM = (140, 105)  # 4:3 at the §7.3 height (Ruling 1)
CONTEXT = 3.0
UNKNOWN_COLOUR = "#8F7BFF"
UNKNOWN_TYPE = "Unknown type"


def finding_figures(ctx: ComposeContext, finding: FindingRow) -> list[Figure]:
    """The image anchor's main figure: its annotation cropped with context (spec §9.2), with the
    locator inset when `context_inset`; [] for other anchors or a box/image that no longer exists."""
    if finding.anchor_kind != "image":
        return []
    with ctx.handle.session() as s:
        from app.db.models import Finding

        current = s.get(Finding, finding.id)
        annotation_id = current.annotation_id if current is not None else None
        box = s.get(Box, annotation_id) if annotation_id else None
        img = s.get(Image, box.image_id) if box is not None else None
        if box is None or img is None:
            return []
        ptype = s.get(ProjectType, finding.type_id)
        ring = _ring(box)
        image_id, file_name = img.id, PurePosixPath(img.path).name
        name = ptype.name if ptype is not None else UNKNOWN_TYPE
        colour = ptype.colour if ptype is not None else UNKNOWN_COLOUR
    spec = ImageCropSpec(
        kind="image_crop",
        image_id=image_id,
        ring=ring,
        colour=colour,
        label=f"{format_number(finding.number)} · {name}",
        context=CONTEXT,
        out=list(MAIN_OUT),
        inset=_context_inset(ctx),
    )
    return [
        Figure(kind="figure", snapshot=_ref(ctx, spec), caption=file_name, width_mm=MAIN_MM[0], height_mm=MAIN_MM[1])
    ]


def _ring(box: Box) -> list[list[float]]:
    """Image-px ring by shape (Ruling 4): a point is one vertex; a polygon without points falls back
    to its envelope."""
    if box.shape == "point":
        return [[float(box.x), float(box.y)]]
    pts = outline(box)
    if not pts:
        pts = corners_of(box.x, box.y, box.w, box.h, 0.0)
    return [[float(x), float(y)] for x, y in pts]


def _context_inset(ctx: ComposeContext) -> bool:
    for section in ctx.config.sections:
        if section.key == "finding_pages":
            return bool(getattr(section.options, "context_inset", True))
    return True
```

```python
"""The `attachment` snapshot: a finding photo at print size (reports index, coordinator ruling 2;
unit R9-I). One file per render, JPEG-draft-reduced to the smallest scale that still covers `out`,
EXIF-upright, fitted inside `out` and padded white (paper). R3's `render_to_cache` encodes it as the
cached JPEG (q85, 4:2:0, no EXIF) and turns any exception here into a placeholder with the reason."""

from __future__ import annotations

from pathlib import Path

from PIL import Image as PILImage
from PIL import ImageOps

from app.db.models import FindingAttachment

PAPER = (255, 255, 255)


def _path(handle, spec) -> Path:
    """The attachment's file, or LookupError: unknown row, another finding's row, a path outside
    `<project>/findings/`, or a file that is gone."""
    with handle.session() as s:
        row = s.get(FindingAttachment, spec.attachment_id)
        if row is None or row.finding_id != spec.finding_id:
            raise LookupError("The photo no longer exists.")
        rel = row.path
    root = (handle.folder / "findings").resolve()
    path = (handle.folder / rel).resolve()
    if not path.is_relative_to(root):
        raise LookupError("The photo is not inside the project's findings folder.")
    if not path.is_file():
        raise LookupError("The photo file is missing.")
    return path


def source_version(handle, spec) -> str:
    """size:mtime_ns of the file, or "missing" (compose never raises on a vanished photo)."""
    try:
        st = _path(handle, spec).stat()
    except (LookupError, OSError):
        return "missing"
    return f"{st.st_size}:{st.st_mtime_ns}"


def render(handle, spec) -> PILImage.Image:
    out_w, out_h = int(spec.out[0]), int(spec.out[1])
    side = max(out_w, out_h)
    with PILImage.open(_path(handle, spec)) as im:
        if im.format == "JPEG":
            im.draft("RGB", (side, side))  # square request: still covers `out` after a 90 degree turn
        upright = ImageOps.exif_transpose(im)
        if upright.mode in ("RGBA", "LA", "P"):
            rgba = upright.convert("RGBA")
            flat = PILImage.new("RGB", rgba.size, PAPER)
            flat.paste(rgba, mask=rgba.getchannel("A"))
            upright = flat
        else:
            upright = upright.convert("RGB")
        fitted = ImageOps.contain(upright, (out_w, out_h), PILImage.Resampling.LANCZOS)
    page = PILImage.new("RGB", (out_w, out_h), PAPER)
    page.paste(fitted, ((out_w - fitted.width) // 2, (out_h - fitted.height) // 2))
    return page
```
