## Rulings (spec ambiguities decided here)

1. **Existing operations keep their shape; new fields are additive.** `createBox`/`updateBox` answer
   `BoxWriteResult` = `Box` + `repaired` + `finding_id` (flat, `allOf`), not the spec's nested
   `{box, finding_id, repaired}`: every existing caller reading a `Box` keeps working. `getImage`
   and `updateImage` answer `ImageDetail` = `Image` + `camera` + `footprint` + `footprint_kind`.
   `BoxReviewResult` keeps `updated` (the spec says `changed`) and adds
   `finding_ids_created`/`finding_ids_deleted`.
2. **`BoxCreate` requires only `class_id`.** `shape` is `box` when absent; `box`/`rbox` need
   `x, y, w, h`; `polygon` needs `points` (the server derives the envelope); `point` needs `x, y`.
   A missing field is `422 invalid_shape`. For rectangles the server derives `box`/`rbox` from
   `angle` (non-zero ⇒ `rbox`) on every create and update — the same rule migration `0011` applies to
   existing rows. `BoxUpdate` gains `points` (polygons only); the shape never changes through an
   update. Bounds refusals get their own code `out_of_bounds` (today they are `validation_error`,
   which `REFUSES_VALID_DATA` forbids) — I-BA renames it.
3. **`preannotateImage` is deprecated, not removed**, with `x-retire-with: I-FW` (its last frontend
   caller, `frontend/src/api/images.ts:preannotateImage` used by `editor/useEditorImage.ts`, goes
   when FW deletes `editor/*`). I-BP may delete the backend route earlier (spec §19), which
   `RETIRING` allows; I-FW deletes the path, `PreannotateRequest`/`PreannotateResult`, the
   frontend helper and the `RETIRING` entry, and regenerates the client.
4. **`image_summary` is seeded by migration `0011`** with one `INSERT … SELECT` (pure SQL, no rows in
   Python, cannot fail on data), so the index is correct at first open; the `summary_rebuild` job
   (I-BX) is the repair tool. The seeded semantics are the contract for `summary.touch`:
   `annotation_count` = boxes with `review_state IN ('accepted','edited') AND shape <> 'point'`;
   `pending_count` = boxes with `review_state = 'unreviewed'`; `max_pending_conf` = `MAX(confidence)`
   over those, null when none.
5. **`Image.finding_count` and `Image.worst_severity`** (and the index's `count`/`sev`) count the
   image's findings whose status is **not `closed`**. `Image.reviewed` = no unreviewed proposal is
   left **and** (the image has ground truth **or** is marked empty).
6. **Filters.** `getImageIndex` and `listImages` share seven component parameters
   (`has_findings`, `severity` csv of 1–9, `finding_status` csv, `type_ids` csv, `has_suggestions`,
   `reviewed`, `unlabeled`); `listImages` keeps its legacy `labeled`/`has_pending` for old callers.
   `detectImageBatch`'s `scope.filter` is the same set as a body object, `ImageFilter`.
7. **Image measurements** are capped at 500 per image (`422 too_many_measurements`); the list is
   one unpaged array (bounded by the cap). `length_mm`/`sigma_mm` are null while no distance rule
   applies.
8. **Assist import is a job too.** `importAssistModel` queues `assist_acquire` with `{key, path}`
   (hash and copy of a ~78 MB file, measured by I-BS), answering 202 like `acquireAssistModel`.
9. **Distance seam.** Measurements (BA) need the GSD that BK computes, and BA ∥ BK. C0 adds
   `app/imagery/camera.py:scale(image) -> Scale | None`, answering `None` ("px only", spec §9.3
   rule 4) until BK implements it. This is a fourth seam beyond the three the dispatch named.
10. **`summary.touch` takes the box service's `Session`** (`touch(s: Session, image_id: str)`), not a
    `conn`: every box write in `datasets/boxes.py` runs on a SQLAlchemy session `s`.
11. **Job modules are per unit** so batch-2 units never edit one file: `imagery/jobs_metadata.py`
    (BK), `imagery/jobs_summary.py` (BX), `assist/jobs_acquire.py` (BS); each registers its type
    with a body that raises `JobFailure("not implemented")`, imported by its unit's route module.
12. **`previewLibraryDataset` gains an optional `task` query parameter** (`ModelTask`, `detect` when
    absent): `DatasetPreview.skipped_by_task` cannot be computed without a task, and the preview
    body is a bare `DatasetFilter`.
13. **The frontend's `yolo_seg` option row** in `exports/ExportForm.tsx` is not added here (C0 adds
    only the `DEFAULT_SELECTED` key TypeScript forces); I-BT adds the row with its writer.
