## Rulings

1. **Interim host.** Until R7, `ReportsPlaceholder` (R7 deletes it) renders `h1 Reports`, a `Segmented` `Reports | Data exports` (accessible name "Reports view") that navigates between `/reports` and `/reports/exports`, and either the old empty state or the panel. Both routes point at it. This mirrors the spec §12 shape so the operator sees the final structure now.
2. **The panel owns no page chrome**: no `h1`, no outer padding; a one-line intro paragraph and `h2` sections only. Its root is a `section` named "Data exports" so tests and R7 can find it.
3. **The panel takes `projectId` as a prop**, not `useParams`, so R7's host decides where it comes from.
4. **The More menu loses "Export"** (`SECONDARY_PAGES`): Data exports is now under the Reports tab; a secondary page that only redirects would duplicate it. The palette's "Go to" list follows `SECONDARY_PAGES`, so it loses it too.
5. **`resultTarget`** for `map_export` and `detect_export` points at the new route with label "Open data exports" (a toast link through a redirect would work, but the redirect is legacy). `volume_export` and `pointcloud_export` keep their workspace targets.
6. **Past exports rows name their kind** (`jobTitle(job)`, e.g. "Point cloud export"): with five kinds in one list, a row without its kind is ambiguous. `isFileExport` widens to `volume_export` and `pointcloud_export`, whose results already carry `{folder, files}` (`volumes/jobs_export.py:288`, `pointclouds/jobs_export.py:73`), so "Show in folder" and the file list work for them.
7. **CSV only, no format switch**: with one format left, `DetectExportForm` drops its `Segmented` and states the CSV hint as plain text; it still posts `{ format: "csv" }` (+ `source_id`).
8. **Links to the workspaces** (map, point clouds, volumes) sit in one "Exports in their workspaces" section of the panel. The volume bundle gets a link too (spec §13 keeps it in its workspace; §18 criterion 6 wants every earlier export reachable).
9. **Copy**: the `ExportForm` "Include suggestions…" sentence says "the contact sheet" instead of "the report". Nothing else in `html_out.py` changes.

## Deviations from the spec

- Spec §12 puts `/reports/exports` inside `ReportsTab.tsx`; that is R7's. R8 routes it through the interim placeholder (Ruling 1), as the index's frontend table allows.
- Spec §13 says "a button that creates a report"; per Coordinator ruling 7 it is a link that navigates to `/p/:id/reports?new=builtin-survey-counts`, and R7 creates the report. Until R7 merges, the link lands on the placeholder's Reports view.
