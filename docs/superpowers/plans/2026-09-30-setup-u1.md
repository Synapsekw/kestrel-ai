## Review Focus

The five likeliest real-world breakages, each with the test that pins it:

1. **An existing `catalogue.db` at `0002` (archived duplicates and hotkeys included) opens after `0003` with every type intact.** SQLite cannot alter a CHECK, so `0003` rebuilds `catalogue_type`. A rebuild that loses the `WHERE` of `ux_catalogue_type_live_name`/`_live_hotkey` makes the copy fail on an archived "crack" next to a live "Crack", and the catalogue (with every type) stops opening. The migration drops both indexes before the batch and re-creates them with their `WHERE` after. Pinned by `test_catalogue_migration_0003.py::test_a_0002_catalogue_upgrades_and_keeps_every_type` and `::test_the_live_name_and_hotkey_indexes_stay_partial` (Task 5).
2. **The seeded built-ins are exactly the code's, and are seeded once.** The frozen copy in `0003` and `app/setup/builtins.py` can drift; a re-run could duplicate or overwrite. Pinned by `::test_the_migration_carries_a_frozen_copy`, `::test_the_seeded_rows_are_the_code_built_ins` and `::test_the_built_ins_are_seeded_once` (Task 5), and `test_setup_builtins.py` (the spec §5.1 table).
3. **Downgrade keeps every type.** `0002`'s check has no `template`, so a naive downgrade fails on a template-made type. `0003`'s downgrade folds `template` into `user` first and keeps the partial indexes. Pinned by `::test_0003_downgrades_to_0002_and_keeps_every_type` (Task 5).
4. **Catalogue answers and writes keep working before U2 stores the new fields.** `CatalogueType` now requires `definition` and `severity_rules`, while `CatalogueTypeRef` (U2's) has neither, and `create_type(**body.model_dump())` would raise `TypeError` (a 500) on the new keys. `CatalogueTypeOut` defaults both, and the create route excludes them until U2. Pinned by `test_setup_contract.py::test_a_type_answer_carries_both_new_keys_before_u2_fills_them`, `test_setup_catalogue_fields.py::test_a_create_or_patch_that_sends_them_is_taken` and schemathesis `test_contract.py::test_responses_conform` for the catalogue operations (Task 1). The frontend side (typed `CatalogueType` fixtures) is pinned by `pnpm -C frontend build` in Task 1.
5. **A broken `app.setup` import costs only the setup endpoints, never the app** (AGENTS.md: the app must start). Pinned by `test_setup_router_guard.py` (Task 4); a failed `0003` is covered by the existing `test_catalogue_db.py::test_the_app_starts_when_the_catalogue_cannot_open`.

## Rulings (taken while planning; reviewers should not flag them)

1. **Stubs live in the owner's module; `EXPECTED_STUBS` is derived** (Reports R0 Ruling 1). `routes_templates.py` (U2) and `routes_inspect.py` (U3) export `router` and `STUBS`; `app/catalogue/router.py` gets a module-level `STUBS` for `ensureCatalogueTypes` (U2). `app.setup.router.stub_operation_ids()` collects all three, and `tests/test_contract.py` does `EXPECTED_STUBS |= setup_stub_operation_ids()`. An owner drops its `STUBS` and nothing else changes.
2. **`CatalogueTypeOut.definition` and `.severity_rules` are defaulted, not required, in pydantic** (the contract requires them). `from_ref(**asdict(ref))` keeps working with today's `CatalogueTypeRef`, and when U2 appends `definition: str | None = None, severity_rules: tuple = ()` to the ref, `from_ref` passes them through with no U1 change. A pydantic default is always serialised, so every answer carries both keys.
3. **Until U2, the create route accepts and drops the two fields** (`body.model_dump(exclude={"definition", "severity_rules"})`); the patch route needs nothing (`patch_type` ignores unknown keys). U2 deletes the `exclude`. This keeps `createCatalogueType` from a `TypeError` 500 under schemathesis.
4. **`listCatalogueTypes`'s `origin` query enum gains `template`** in the contract and the route's type (`TypeOrigin`); the service already filters by equality (coordinator ruling from the U2 planner).
5. **`SlotMatch` never serialises a null** (coordinator ruling from the U2 planner). In pydantic, `None` means "absent" (`raster: RasterMatch | None = None`), so U3's `SlotMatch(**match)` works whatever its dict holds, and a `model_serializer(mode="wrap")` drops `None` keys wherever the model is nested. The contract keeps both keys optional and non-null. `TemplateSlot.match: SlotMatch | None` keeps `null`. Pinned by `test_setup_contract.py::test_a_slot_match_never_serialises_a_null` (including a FastAPI round trip).
6. **`CatalogueTypeSpec` is one schema** with `required: [name, kind]` (index: a request needs only those). The index also asks that "every property is required inside `ProjectTemplate`"; one schema cannot say both, so the pydantic defaults make every dump carry all seven keys (pinned by `test_a_type_spec_needs_only_a_name_and_a_kind_and_dumps_every_key`), and the description says so. The generated TypeScript type has optional fields; U5 reads them with `?? null` (Coordinator question 2).
7. **`ProjectTemplateOut`** is the pydantic name of the contract's `ProjectTemplate` (like `CatalogueTypeOut`), so it never shadows the ORM class `app.catalogue.db.ProjectTemplate`.
8. **The built-in Confined template is seeded in its pre-S4 state:** Inspection video `required: false`, Stills `required: true` (spec §5.1 "until S4 merges … Stills is the required slot"). S4 flips it with a new catalogue revision (Coordinator question 1).
9. **Slot `accepts` promise only what today's importers take** (S1-5): photos `jpg, jpeg` (`app.datasets.prepare.IMAGE_EXTS` has no `.dng`), GeoTIFF `tif, tiff`, clouds `las, laz`, drawings `pdf, dxf, xml`, video `mp4, mov`. Pinned by `test_setup_builtins.py::test_a_slot_promises_only_what_its_importer_takes`.
10. **Error codes:** `template_builtin` (409), `template_name_taken` (409, details `{template_id}`), `invalid_template` (422, details `{errors: [{path, message}]}`, the code Reports already uses), `invalid_severity_rule` (422, details `{name, severity}`), `type_name_blank` (422, details `{name}`, coordinator ruling from the U2 planner). `ensureCatalogueTypes`'s 422 also names `severity_unknown` (a default severity above the scale, the catalogue service's existing code).
11. **`startSetupInspect` refuses only malformed bodies.** A relative, missing or unreadable path is listed under `not_recognised` (spec §11), and an unknown `template_id` leaves every `slot_key` null, so no `REFUSES_VALID_DATA` entry is needed. The contract summary says so (Coordinator question 3).
12. **`createProject` now declares its 422**, in U2's codes (the U2 plan's ruling 10): `unknown_type` for a type id the catalogue does not know, `hotkey_invalid` (details `{type_ids}`) for a `hotkeys` key outside `type_ids`; its 409 also names `hotkey_conflict`. So `UNDECLARED_REFUSALS["createProject"]` is deleted; `REFUSES_VALID_DATA["createProject"]` stays.
13. **Head tests follow the one-head-and-on-it pattern** (commit `4db5df2d`): `test_catalogue_db.py`'s head test asserts one head with `0003` on it, and `test_catalogue_migration_0002.py`'s version check becomes `>= "0002"`, so `0004` will not break either.
14. **`setup_inspect` labels:** title "Sort dropped files", verb "Sorting files" (U3 planner), icon `folder`, toast "Dropped files sorted"; on success it links to `/projects/new` ("Open new project"), and `REPORTED_ON` keeps the toast quiet on that page, whose Data card shows the result.

## Budget

**U1's share: no background work and no new read.** Every new operation answers 501; `setup_inspect` is only a name in the enum (U3 registers it). Migration `0003` runs once per catalogue: it copies `catalogue_type` once (hundreds of rows at most) and inserts three rows, so it cannot fail on user data; if it failed anyway, the existing startup path leaves `catalogue` at `None` and the app starts, and templates are unavailable. The contract **encodes** the index's budget so the owners cannot drift (pinned by `test_setup_contract.py::test_the_contract_encodes_the_budget`):
- **Background job:** `startSetupInspect` answers 202 `JobRef` (`setup_inspect`, library runner). No S1 request does long work in the request.
- **Bounded reads and results:** `SetupInspectRequest.paths` ≤ 16; `InspectBucket.files` ≤ 200 and `samples` ≤ 200 (`count` and `bytes` are totals); `InspectNotRecognised.samples` ≤ 50; `truncated` when the walk stops at 50,000 files (U3); `EnsureTypesRequest.types` 1–64 and `EnsureTypesResult.items` ≤ 64; `TemplateConfig.slots` ≤ 16 and `types` ≤ 64; `severity_rules` ≤ 8; `definition` ≤ 1000.

def _phantom_keys(node, path):
    """An unquoted comma in a flow-mapping description makes a None-valued key with a space."""
    found = []
    if isinstance(node, dict):
        for k, v in node.items():
            if v is None and isinstance(k, str) and " " in k:
                found.append((path, k))
            found += _phantom_keys(v, path + [k])
    elif isinstance(node, list):
        for i, v in enumerate(node):
            found += _phantom_keys(v, path + [i])
    return found

"""Pydantic shapes of the catalogue schemas in contract/openapi.yaml."""

from dataclasses import asdict
from typing import Literal

from pydantic import BaseModel, ConfigDict, Field

from app.catalogue.service import CatalogueTypeRef, SeverityLevelRef

HEX = r"^#[0-9a-fA-F]{6}$"
HOTKEY = r"^[1-9A-Za-z]$"
NOT_BLANK = r"\S"
TypeKind = Literal["defect", "object"]
TypeOrigin = Literal["user", "migrated", "template"]
TYPE_ORIGINS: tuple[str, ...] = ("user", "migrated", "template")
# Project setup (spec 2026-09-30-project-setup section 5, plan 2026-09-30-setup-u1).
DEFINITION_MAX = 1000
MAX_SEVERITY_RULES = 8


class SeverityRule(BaseModel):
    """One of a type's ordered severity rules. Whether `severity` is a level on the current scale is
    the service's own 422 (`invalid_severity_rule`, unit U2), never pydantic's."""

    model_config = ConfigDict(extra="forbid")

    when: str = Field(min_length=1, max_length=200, pattern=NOT_BLANK)
    severity: int = Field(ge=1, le=9)


class CatalogueTypeOut(BaseModel):
    id: str
    name: str
    colour: str
    kind: TypeKind
    default_severity: int | None
    hotkey: str | None
    group: str | None
    archived: bool
    origin: TypeOrigin
    # Defaulted until U2 adds both fields to CatalogueTypeRef (plan 2026-09-30-setup-u2); `from_ref`
    # then passes them through. A default is always serialised, so every answer carries the two keys
    # the contract requires.
    definition: str | None = Field(None, max_length=DEFINITION_MAX)
    severity_rules: list[SeverityRule] = Field(default_factory=list, max_length=MAX_SEVERITY_RULES)

    @classmethod
    def from_ref(cls, ref: CatalogueTypeRef) -> "CatalogueTypeOut":
        return cls(**asdict(ref))


class CatalogueTypePatchOut(CatalogueTypeOut):
    backfill_candidates: bool = False


class CatalogueTypePage(BaseModel):
    items: list[CatalogueTypeOut]
    next_cursor: str | None = None
    needs_classification: bool = False


class CatalogueTypeCreate(BaseModel):
    name: str = Field(min_length=1, max_length=64)
    colour: str | None = Field(None, pattern=HEX)
    kind: TypeKind = "object"
    default_severity: int | None = Field(None, ge=1, le=9)
    hotkey: str | None = Field(None, pattern=HOTKEY)
    group: str | None = Field(None, max_length=64)
    definition: str | None = Field(None, max_length=DEFINITION_MAX)
    severity_rules: list[SeverityRule] = Field(default_factory=list, max_length=MAX_SEVERITY_RULES)


class CatalogueTypePatch(BaseModel):
    """Every field optional; `model_dump(exclude_unset=True)` is the patch. `default_severity`,
    `hotkey`, `group` and `definition` accept null (clear)."""

    name: str = Field(default=None, min_length=1, max_length=64)
    colour: str = Field(default=None, pattern=HEX)
    kind: TypeKind = Field(default=None)
    default_severity: int | None = Field(None, ge=1, le=9)
    hotkey: str | None = Field(None, pattern=HOTKEY)
    group: str | None = Field(None, max_length=64)
    archived: bool = Field(default=None)
    definition: str | None = Field(None, max_length=DEFINITION_MAX)
    severity_rules: list[SeverityRule] = Field(default=None, max_length=MAX_SEVERITY_RULES)


class SeverityLevelOut(BaseModel):
    level: int = Field(ge=1, le=9)
    name: str = Field(min_length=1, max_length=32)
    colour: str = Field(pattern=HEX)

    @classmethod
    def from_ref(cls, ref: SeverityLevelRef) -> "SeverityLevelOut":

class SeverityScale(BaseModel):

"""Pydantic shapes of the project-setup schemas in contract/openapi.yaml (spec
2026-09-30-project-setup sections 5, 7 and 9; plan 2026-09-30-setup-u1).

The models state exactly what the contract states. A rule the schema cannot express (a slot key or
a type name twice, two types with one hotkey) is the owner's own 422 (`invalid_template`, unit U2),
never pydantic's `validation_error`. The catalogue-facing shapes (`CatalogueTypeSpec`, the ensure
request and result) live in app/catalogue/schemas.py.
"""

from datetime import datetime
from typing import Annotated, Any, Literal

from pydantic import BaseModel, ConfigDict, Field, StringConstraints, model_serializer

from app.catalogue.schemas import NOT_BLANK, CatalogueTypeSpec

SlotRoute = Literal["images", "map", "elevation", "pointcloud", "drawing", "video"]
SLOT_ROUTES: tuple[str, ...] = ("images", "map", "elevation", "pointcloud", "drawing", "video")
RasterMatch = Literal["ortho", "elevation"]
SLOT_KEY = r"^[a-z][a-z0-9_]{0,31}$"
EXTENSION = r"^[a-z0-9]{1,10}$"
# Bounds (spec section 10, index "Budget").
MAX_SLOTS = 16
MAX_TEMPLATE_TYPES = 64
MAX_INSPECT_PATHS = 16
MAX_BUCKET_FILES = 200
MAX_BUCKET_SAMPLES = 200
MAX_NOT_RECOGNISED_SAMPLES = 50

Extension = Annotated[str, StringConstraints(pattern=EXTENSION)]
PathText = Annotated[str, StringConstraints(min_length=1)]


class SlotMatch(BaseModel):
    """Both keys are optional and never null in the contract: an absent key matches either value.
    `None` means absent, and the serializer drops it, so `SlotMatch(raster="ortho")` and
    `SlotMatch(raster="ortho", thermal=None)` both dump as `{"raster": "ortho"}` wherever they are
    nested (a template's slots, an inspect bucket, a FastAPI answer)."""

    model_config = ConfigDict(extra="forbid")

    raster: RasterMatch | None = None
    thermal: bool | None = None

    @model_serializer(mode="wrap")
    def _drop_absent(self, handler) -> dict[str, Any]:
        return {k: v for k, v in handler(self).items() if v is not None}


class TemplateSlot(BaseModel):
    model_config = ConfigDict(extra="forbid")

    key: str = Field(pattern=SLOT_KEY)
    label: str = Field(min_length=1, max_length=48)
    route: SlotRoute
    required: bool
    accepts: list[Extension] = Field(min_length=1, max_length=12)
    match: SlotMatch | None


class TemplateConfig(BaseModel):
    model_config = ConfigDict(extra="forbid")

    config_version: Literal[1]
    slots: list[TemplateSlot] = Field(max_length=MAX_SLOTS)
    types: list[CatalogueTypeSpec] = Field(max_length=MAX_TEMPLATE_TYPES)


class ProjectTemplateOut(BaseModel):
    """Contract schema `ProjectTemplate`. Named `...Out` like `CatalogueTypeOut`, so it never shadows
    the ORM class `app.catalogue.db.ProjectTemplate`."""

    id: str
    name: str
    description: str
    builtin: bool
    config: TemplateConfig
    created_at: datetime
    updated_at: datetime


class ProjectTemplatePage(BaseModel):
    items: list[ProjectTemplateOut]


class ProjectTemplateCreate(BaseModel):
    model_config = ConfigDict(extra="forbid")

    name: str = Field(min_length=1, max_length=80, pattern=NOT_BLANK)
    description: str = Field("", max_length=300)
    config: TemplateConfig


class ProjectTemplatePatch(BaseModel):
    """Every field optional; `model_dump(exclude_unset=True)` is the patch. None is nullable."""

    model_config = ConfigDict(extra="forbid")

    name: str = Field(default=None, min_length=1, max_length=80, pattern=NOT_BLANK)
    description: str = Field(default=None, max_length=300)
    config: TemplateConfig = Field(default=None)


class SetupInspectRequest(BaseModel):
    """`paths` are meant to be absolute, but a relative, missing or unreadable one is listed under
    `not_recognised` by the job (U3), never refused here."""

    model_config = ConfigDict(extra="forbid")

    paths: list[PathText] = Field(min_length=1, max_length=MAX_INSPECT_PATHS)
    template_id: str = Field(default=None, min_length=1)


class InspectBucket(BaseModel):
    route: SlotRoute
    match: SlotMatch
    slot_key: str | None
    folder: str
    files: list[str] = Field(max_length=MAX_BUCKET_FILES)
    count: int = Field(ge=0)
    bytes: int = Field(ge=0)
    samples: list[str] = Field(max_length=MAX_BUCKET_SAMPLES)
    crs: str | None


class InspectSkipped(BaseModel):
    name: str
    reason: str


class InspectNotRecognised(BaseModel):
    count: int = Field(ge=0)
    samples: list[InspectSkipped] = Field(max_length=MAX_NOT_RECOGNISED_SAMPLES)


class InspectResult(BaseModel):
    """The `result` of a `setup_inspect` job: U3 stores `InspectResult(...).model_dump(mode="json")`."""

    buckets: list[InspectBucket]
    not_recognised: InspectNotRecognised
    suggested_template_id: str | None
    truncated: bool
